Groton Maze Learning Test

Spatial Working Memory Assessment

Instructions

In this task, you will need to find the hidden pathway.

You will complete 5 trials using the same hidden path.

Task Steps

  • Tap the blue tile in the top-left corner to begin.
  • Tap one tile at a time to follow the hidden path to the yellow tile in the bottom-right corner.
  • A green check mark means your choice was correct; a red X means it was wrong.
  • If you make a mistake, tap the last green tile again, then try a new direction.
  • Only move to tiles directly above, below, left, or right—never diagonally.
  • Do not tap the same tile more than once in a trial.
  • Move quickly but stay accurate; the timer starts when you tap the first tile.
